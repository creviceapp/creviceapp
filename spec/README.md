# Crevice Developer Specification

This document set defines the implementation contract for Crevice4. It is written for implementers, maintainers, reviewers, test authors, and release operators. It is not a user guide.

Section 1 defines the writing rules, vocabulary, document responsibilities, and source boundaries for the rest of the specification.

## Reading Model

Each numbered document is normative for the implementation area named by its title. Appendix A defines stable test coverage identifiers. Appendix B contains unresolved decisions and future work.

An Appendix B item does not change the implemented contract until it moves into a numbered document or Appendix A.
